# AI Cloak Studio

เครื่องมือใส่ชั้นรบกวน (adversarial-style perturbation) ลงบนภาพ portrait เพื่อลดความแม่นของระบบอ่านภาพอัตโนมัติ ทำงานในเบราว์เซอร์ 100% — ภาพไม่ถูกอัปโหลดขึ้นเซิร์ฟเวอร์ใด ๆ

## ใช้งาน
เปิด `index.html` ในเบราว์เซอร์ หรือเข้าผ่าน GitHub Pages

## เทคนิคในตัว
- **High-frequency noise** — ε-bounded noise ที่ตามนุษย์แทบมองไม่เห็น
- **Patch-grid perturbation** — เล็งกวนจุดที่ vision encoder ตัดภาพเป็น patch (~14px)
- **Micro-warp** — บิดพิกเซลระดับต่ำกว่า 1px ทนการบีบอัดได้ดีกว่า noise
- ปุ่ม **จำลองผ่าน Facebook** — resize + JPEG recompress เพื่อตรวจว่าชั้นกวนเหลือแค่ไหนหลังโพสต์

## ข้อจำกัด
เป็นชั้นเสริม ไม่ใช่เกราะรับประกัน การบีบอัดของแพลตฟอร์มลดผลของชั้นกวนได้ สำหรับข้อมูลลับควรใช้คู่กับการ redact และช่องทางส่งที่เข้ารหัส
